# Project Reignition v1.0.2 — 100% 검수용 세이브

이 ZIP은 선택 다운로드입니다. 한국어 모드를 설치하기 위해 필요하지 않으며, 한국어 모드 없이도 사용할 수 있습니다. 게임 v1.0.2용으로 생성한 검수 프로필이며 실제 플레이 달성 기록은 아닙니다. 다른 버전에서의 동작은 보장하지 않습니다.

## 포함 상태

- 레벨 99, 세계 9개 및 세계 링 7개
- 어드벤처 111개 금메달
- 파이어 소울 배치 스테이지 43개, 총 129개
- 스킬 54개 확인, 스페셜북 업적 30개, 타임 어택 해금

`100%`는 위 상태를 설정한 배포 이름입니다. 파티 모드 등 모든 게임 요소의 전수 달성·검증을 뜻하지 않습니다.

## 권장: 기존 기록과 분리해서 실행

1. 게임을 종료하고 ZIP을 전용 폴더에 풉니다. 예: `C:\Games\Reignition-100-percent`.
2. 해당 폴더 바로 아래에 `saves\save00.dat`과 `saves\shared.dat`이 있는지 확인합니다.
3. **게임 실행 파일 옆**의 `saveLocation.txt`가 있다면 원본을 별도 위치에 복사해 보관합니다. 원래 없었다면 없었다는 사실을 기억하세요.
4. 게임 실행 파일 옆 `saveLocation.txt`를 메모장으로 열거나 만들고, 다음 예시처럼 전용 폴더의 실제 절대 경로만 한 줄로 저장합니다. 경로에 따옴표를 넣지 마세요. `.txt.txt`가 되지 않도록 확장자를 확인하세요.

   `C:/Games/Reignition-100-percent/`

5. 한국어로 보려면 전용 폴더에 `mods\lang`을 만들고 별도로 받은 `Korean.pck`를 넣습니다. 게임에서 Language Mods를 켜고 재시작한 뒤 한국어를 선택하세요. 이 ZIP에는 PCK나 사용자 설정이 포함되지 않습니다.
6. 게임을 실행하고 첫 번째 저장 슬롯을 선택합니다. 게임이 생성하는 설정과 진행 기록도 이 전용 폴더에 저장됩니다.

**원래 기록으로 복귀:** 게임을 종료한 후 백업한 `saveLocation.txt`를 그대로 복원하세요. 원래 파일이 없었다면 이번에 만든 `saveLocation.txt`를 제거하세요. 전용 폴더의 기록을 실제 세이브 폴더로 복사하지 않으면 기존 기록은 유지됩니다.

## 기존 프로필에 직접 적용하고 싶은 경우

분리 실행보다 주의가 필요합니다. `save00.dat`는 첫 번째 슬롯을 대체하며, `shared.dat`는 슬롯 전체에서 공유하는 업적·해금·누적 기록을 대체합니다. 기존 기록과 자동 병합되지 않습니다.

1. 게임을 종료합니다.
2. 현재 사용자 데이터 위치를 확인합니다. 기본값은 `%APPDATA%\Godot\app_userdata\Sonic and the Secret Rings Remake`이며 `saveLocation.txt`를 사용한다면 그 파일이 가리키는 위치입니다.
3. 기존 `saves` 폴더 전체를 사용자 데이터 폴더 밖의 안전한 위치에 백업합니다.
4. ZIP의 `saves` 안에 있는 두 파일을 현재 `saves` 폴더에 복사합니다. 첫 번째 슬롯과 공통 기록을 대체하는 것에 동의하는 경우에만 덮어쓰세요.
5. 게임을 실행하고 첫 번째 슬롯을 선택합니다.

복원하려면 게임을 종료하고 백업한 `saves` 폴더를 원래 상태로 돌려놓으세요. 다른 개인 슬롯을 공유하거나 업로드할 필요는 없습니다.
